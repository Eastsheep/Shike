熱量估算方式

沒有活動紀錄的日子不會多加，避免沒運動時高估。手錶和手機估的活動消耗常偏高，建議計入 75% 或 50%。多出來的熱量會依上面蛋白質、碳水、脂肪目標的比例分配。

連線設定

這些資料只存在這支手機的瀏覽器裡，不會上傳到網頁的程式碼。換手機要重新貼一次。

GitHub（存放紀錄）

到 GitHub → Settings → Developer settings → Fine-grained tokens 建立，只勾選資料 repo，權限 Contents 設為 Read and write。

DeepSeek（AI 估算）

到 platform.deepseek.com 建立 API key。建議只儲值少量金額。
